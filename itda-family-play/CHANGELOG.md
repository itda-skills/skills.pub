놀이 스킬팩.

## [0.8.0] - 2026-09-10

### Changed

- **`papercraft-box` 0.9.0 — 타일 인쇄 균등 분할 (#1679).**
  종전에는 첫 장을 인쇄 영역(194mm)까지 꽉 채우고 나머지를 다음 장에 넘겨, **마지막 장이 잘린 조각**이 됐다
  (26cm 정사각 지도 = 194 + 84mm). 부품이 인쇄 영역을 살짝만 넘으면 마지막 장이 십수 mm 짜리 종잇조각이 되어
  이어 붙이기가 사실상 불가능했다. 장수(열·행)는 인쇄 영역이 정하고 **그 안에서 보폭을 균등 재분배**하도록 바꿨다
  (`sw = (W - overlap) / cols`) — 장수는 그대로이므로 손해 없이 139 + 139mm 가 된다.
- 부수 교정 두 건. ① `draw_tile` 이 클립·겹침 점선·정렬 십자를 **인쇄 영역** 기준으로 그려, 내용이 그보다 좁은
  마지막 장에서 십자가 빈 종이를 가리켰다(종전에도 틀린 표시였다) → **그 타일의 실제 크기** 기준으로.
  ② `tile_page` 판정이 고정 좌표로 십자를 찾아, 십자가 옮겨가면 타일 쪽을 못 알아보고 기하 검사를 태웠다 →
  `(MARGIN, MARGIN)` 에서 시작하는 직사각형으로 찾되, 십자를 **가로+세로 두 선의 교차**로 좁혀 오인을 막았다
  (한쪽만 보면 같은 길이의 접는 선이 걸려 **일반 쪽이 검사에서 통째로 빠진다**).
- 기존 계약 테스트 3건은 상수(`aw - overlap`)가 아니라 **불변식**(균등·완전 피복·인쇄 영역 상한)을 재도록 다시 썼다.
  기대값 반전 이력을 테스트 안에 남겼다 — 상수로 되돌리지 마라. 뮤테이션 5종 전건 RED 실측.

## [0.7.0] - 2026-09-08

### Changed

- **`papercraft-box` 0.8.0 — Codex(gpt-6-astra) 적대 리뷰 반영: 활·화살 결속 재설계 + 검증 강화 (#1663).**
  0.6.0/0.7.0 의 결속 기하가 틀렸다 — 활 판과 화살대가 **같은 평면**이라 손잡이 구멍을 "관통"할 수 없고(양옆 채움과
  충돌, 촉 24mm 가 8mm 구멍 통과 불가), 발사용은 화살을 활 평면에 수직으로 둬 꼬리가 시위에서 50mm 떨어졌다.
  좌표 포함만 재던 테스트가 이를 통과시켰다. 재설계: 화살은 활 **앞면에 같은 방향으로 눕혀**(`layout.plane: "xy"` 신설 —
  2D 깃 실루엣의 홈이 시위 방향으로 열린다) 놓고 손잡이 **종이 고리**(가로 슬릿 2 + 띠)로 붙잡는다. 시위는 구멍 → **오늬
  접점**(`cords` 자유점 `{"at":[x,y,z]}` 신설) → 구멍으로 꺾인다. 발사용은 화살대 `axis: "x"`, 앞면 **받침 선반**(flat +
  tab), 깃은 관 위·앞, 오늬는 세로 가위집. 게이트 `tests/test_bow_geometry.py` 가 **고체 교차 0·접촉 실재·시위가 화살
  고체를 지나지 않음**을 잰다(`tests/_geom.py`).
- 검증 강화: `holes` 는 원 ↔ 빈 칸 **정확 교차**(5점 표본이 놓치던 모서리 물림 거부) · `slots` 는 실루엣 안으로 **클립**
  (부품 밖으로 절단선이 나가지 않음) + 구멍 침범 거부 · `tube` 는 유한 수·양수 풀 띠·정수 겹 수만, 194mm 띠도 verify 가 검사
  (`width>500` 제외 완화) · `cords` 는 `i` 정수·범위·`d_mm` 양수·`plan` 에서도 검증 · `hexcol` 은 `#RGB` 허용 + 잘못된 색
  명시 에러 · 짧은 관의 안내 문구는 띠 안에 클립/생략 · 관 자동 안내가 조립 안내와 충돌하지 않게(심 처리는 조립 안내를 따름,
  관 띠는 일반지).
- 문서: design-guide §6·§7 오판 이력 명시 + 재설계, spec-format(정확 교차·클립·자유점·xy·tube 계약), GUIDE·SKILL 의
  확정형 서술을 **미실측** 표시로 완화. Codex findings 17건 트리아지는 #1663.
- **R2(같은 모델 재리뷰) 반영**: 시위 접점은 끈 **중심선**이라 고체 표면에서 끈 반지름만큼 뗀다(전시용 `[15.5,-0.5,60]` —
  대 끝면과 뒤 깃 앞면 모서리: 장력 합력이 +y 뿐이라 시위는 홈 중앙이 아니라 뒤 깃 앞면에 눌린다, 풀 한 점 권장) ·
  발사용 접점은 가위집 **바닥**(꼬리 + `nock_mm`) · 슬롯은 클립 대신 **잘린 형상 자체**(교집합 채움 + 칸 안 절단선)를
  그려 verify 의 bbox 와 가시 영역이 같다 · 구멍 끝점의 `(id,i)` 는 `layout` 에 있어야 하고 자유점은 두 끈이 만나야 한다
  (끊긴 시위 거부) · 게이트에 띠 길이/폭 ≥ 경로, 받침 날개가 활 채움 위, 깃이 관 길이 안, 시위 연속, `nock_mm>0`,
  예제 3종 `build --render` 통합을 추가(R2 가 구성한 통과 배치 5종 전부 RED).

## [0.6.0] - 2026-09-08

### Added

- **`papercraft-box` 0.7.0 — 발사용 활: `tube` 부품(종이를 말아 만드는 관) + 24cm 쏘는 활 예제 (#1662, 마스터 요청).**
  종이 활은 휘어 탄성을 내지 못하므로 "활은 강체(2겹 사이 나무젓가락 심), 탄성은 고무줄 시위, 화살대는 말아 만든 관"
  으로 분해했다. `tube` 는 띠 한 장(길이 × π·지름·겹 수 + 풀 띠)에 바퀴 확인선·풀 띠·오늬 표시(말고 난 뒤 가위집)를
  인쇄한다. 조감도는 사각 단면 막대(`layout.axis`)로 근사하고, `flat` 은 `layout.plane: "yz"` 로 옆을 보는 판(깃)도
  세울 수 있게 기저 벡터 방식으로 일반화했다(기존 예제 4종의 조감도 PNG 는 바이트 동일 — 일반 좌표는 부동소수 끝자리가
  다를 수 있어 "바이트 동일"은 예제 PNG 범위의 서술이다, #1663 F16 정정).
- 예제 `bow_arrow_shooter.json`: 활 `flat` 24cm(고무줄 구멍 3.5mm·손잡이 안쪽 변 받침 홈 `slots`) + 화살대 `tube`
  Ø6×170·3겹 + 깃 `flat` 2장. 촉은 도안 없이 **지우개 조각·스펀지 끼우기 안내**(마스터 결정), 안전 문구 포함.
- `tests/test_tube.py`: 띠 치수식·거부·PDF 요소·조감도 쿼드·yz 판·예제 기하(대가 받침 홈을 지나고 꼬리가 시위에 닿음).
- 문서: spec-format(tube·plane·axis), design-guide §7 발사용 활, paper-guide(심·말기), GUIDE FAQ(안전).

### 알려진 제약

- 사거리·정확도는 보증하지 않는다(고무줄·종이·당김에 달렸다). 실측은 마스터 인쇄·조립 후.

## [0.5.0] - 2026-09-08

### Added

- **`papercraft-box` 0.6.0 — 부품 결속 프리미티브 + 활에 걸리는 화살 (#1661, 마스터 요청).**
  활과 화살 도안이 실물에서 따로 놀았다 — 스펙에 둘을 결합하는 기하가 없었고 `assembly` 가
  "걸쳐 놓으면 완성" 이라 적혀 있었다(조감도는 관통하는 것처럼 그려 공백을 가렸다).
  `flat` 부품에 `holes`(펀치 구멍 — 실선 원 + 조준 십자)·`slots`(mm 직사각 절개, 변에 걸친 홈 허용),
  최상위 `cords`(구멍과 구멍을 잇는 끈 — PDF 에는 없고 조감도에만 가는 기둥으로 렌더)를 추가했다.
  빈 픽셀 위 절개, 구멍 없는 자리를 가리키는 끈은 **PDF 이전에 에러**다(조감도와 도안이 같은 말을 한다).
  절개·끈이 있으면 뚫는 요령·끈 재료 안내가 자동으로 실린다.
- 예제 2종: `bow_arrow.json`(시위 끈 — 손잡이 한 칸 관통 + 꼬리 깃 사이 홈에 시위, 두 점 고정) ·
  `bow_arrow_paper_string.json`(종이 시위 유지 — 관통 구멍만). 마스터 결정: 두 방식 모두 지원.
  `tests/test_joints.py` 가 절개 그리기·거부·끈 렌더·활 기하(화살대 = 구멍 높이, 시위 x = 대 끝 x)를 고정한다.
- `references/design-guide.md` §6 결속 절, GUIDE FAQ.

### 알려진 제약

- 발사(고무줄 시위·말아 만드는 화살대·안전촉)는 #1662 로 분리. `prism` 면의 `holes` 는 미지원(flat 만).

## [0.4.0] - 2026-09-07

### Changed

- **`papercraft-box` 0.5.0 — 동봉 폰트 제거, 필요할 때 내려받는다 (#1660, 마스터 지시).**
  `assets/fonts/NanumGothic-Regular.ttf`(2,054,744 B)를 걷어냈다 — 팩 2.2MB 중 **2.0MB(91%)**
  가 이 파일 하나였고, 형제 스킬(pptx-design·xlsx-design)도 시스템 폰트에 의존한다.
  `fontpick` 폴백이 **캐시(`~/.cache/itda-skills/fonts/`) → 내려받기**로 바뀌었다:
  google/fonts **고정 커밋** URL 에서 1회 받아 **sha256 검증** 후 원자적으로 캐시에 둔다
  (받는 파일은 종전 동봉본과 바이트 동일 — 해시 대조 확인). 캐시본도 매번 해시를 검증해
  중단된 다운로드·변조본을 버린다. 실패는 **명시 에러**이며 설치 방법(`fonts-nanum` 등)과
  `PAPERCRAFT_FONT` 직접 지정을 문구에 싣는다.
- 새 환경변수: `PAPERCRAFT_FONT`(파일 직접 지정 — 오프라인·사내망 탈출구),
  `PAPERCRAFT_FONT_CACHE_DIR`, `PAPERCRAFT_FONT_NO_DOWNLOAD`.

### 알려진 제약

- 시스템 한글 TrueType 이 없고 **네트워크도 막힌** 환경에서는 한글 라벨을 찍을 수 없다.
  그 경우 오류가 원인과 처방을 말한다. Cowork 샌드박스의 런타임 다운로드 가능 여부는 미측정이다.

## [0.2.0] — 2026-09-05 (이슈 #1649)

### Added

- **`papercraft-box` 0.2.0 — 조립 완성 조감도.** `render spec.json out.png [--yaw --pitch --scale]` 서브커맨드와
  `build … --render`(도안 뒤에 앞·오른쪽 / 뒤·왼쪽 2시점 조감도 쪽 첨부, `<out>-view-{front,back}.png` 동반).
  텍스처는 `build` 와 같은 `resolve_faces`/`build_grid` 를 쓰므로 인쇄면과 픽셀 단위로 동일하다(등각 투영·법선 명암,
  `scripts/render3d.py`). 풀 날개·종이 두께·원근은 렌더하지 않는다.
- 스펙 `layout` 키 — `[{"id", "at_u": [x,y,z](유닛), "at": [x,y,z](mm), "i"}]` 로 조립 위치를 선언한다. 생략 시 부품을
  바닥에 나란히 놓는다. 예제 3종(steve·robot·nether_portal)에 배치를 넣어 조립 상태로 렌더된다.
- `verify` 는 조감도 쪽(벡터 도형 없이 이미지만)을 날개 검사에서 제외한다 — 종전엔 그 쪽이 FAIL 로 나왔다.
- `tests/test_render3d.py` — 정면 픽셀 = `build_grid` 산출, `open` 면 미렌더, `at`+`at_u` 합산, seed_shift 인덱스, 투영
  방향(뒤가 위·높은 z 가 가까움), PNG 색 존재, 예제 3종 `render`, `build --render` 쪽수 +1·verify PASS·PDF 크기 상한.

### Fixed

- 조감도 쪽 첨부 시 `subset_fonts()` 로 라벨 폰트를 서브셋한다 — 미실행 시 한글 TTF 전체가 실려 PDF 가 6MB+ 로 부풀었다(실측).
- 의존 선언에 Pillow 명시(reportlab 이 끌어오지만 `render3d` 가 직접 import).
