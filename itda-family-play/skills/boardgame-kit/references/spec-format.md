# 스펙 형식

스펙 JSON 한 장이 게임 전부를 정한다. **숫자를 새로 쓰지 말고 `assets/examples/neighborhood.json`
을 복사해 고치는 것**이 안전하다 — 그 스펙은 밸런스가 검증돼 있다.

## 최상위

| 키 | 필수 | 뜻 |
|---|---|---|
| `title` | ○ | 판 중앙과 카드·지폐에 찍히는 제목 |
| `subtitle` | | 제목 아래 한 줄 |
| `ruleset` | | `"monopoly"` (현재 유일) |
| `target_minutes` | | 목표 놀이 시간. 기본 35 |
| `players` | | `{"min": 2, "max": 4, "simulate": 4}` — `max` 가 말·지폐 수를 정한다. `simulate` 를 생략하면 **`max` 로 잰다**(시간 = 라운드 × 인원이라 적은 인원으로 재면 과소평가된다) |
| `victory` | | 승리 조건(아래) |
| `rules` | | 지불 불능 처리(아래) |
| `money` | ○ | 돈(아래) |
| `board` | | `{"tiles": 2}` — A4 몇 장으로 판을 만들지. 2 면 378×378mm 4쪽 |
| `track` | ○ | `{"cells": [...]}` |
| `cards` | | `{"golden_key": [...]}` |
| `images` | | `{"center": "경로", "card_back": "경로"}` — 스펙 파일 기준 상대경로 |
| `theme` | | `{"card": "#D9AF3F", "back": "#2E4A62"}` 카드 앞 띠·뒷면 색 |

## victory — 승리 조건

```json
{"kind": "target_wealth", "value": 320}
```

| kind | value | 언제 끝나나 |
|---|---|---|
| `target_wealth` | 목표 자산 | 현금 + 산 땅값 + 지은 집값이 먼저 목표에 닿은 사람이 승리 **(아이용 기본)** |
| `fixed_rounds` | 라운드 수 | 그 라운드까지 하고 자산이 가장 많은 사람이 승리. 시간이 확정된다 |
| `last_standing` | — | 마지막 한 명이 남을 때까지(원작). **아이용 35분에는 들어오지 않는다** |

어느 조건이든 **혼자만 남으면** 그 자리에서 끝난다.

## rules — 지불 불능

```json
{"bankruptcy": "sell_off", "sell_ratio": 0.5}
```

| bankruptcy | 뜻 |
|---|---|
| `sell_off` | 집 → 싼 땅 순으로 은행에 되팔아(가격 × `sell_ratio`) 낸다. 팔 게 없으면 탈락 **(기본)** |
| `eliminate` | 현금이 모자라면 즉시 탈락(원작) |

## money

| 키 | 뜻 |
|---|---|
| `start` | 1인 초기 자금 |
| `salary` | 출발을 지날 때마다 받는 돈 |
| `start_bonus` | 출발에 **정확히** 멈췄을 때 추가 |
| `unit` | 화폐 단위 글자("냥", "원") |
| `denominations` | 권종 목록. 이 조합으로 `start` 를 **정확히** 만들 수 있어야 한다 |
| `bills` | (선택) 권종별 매수를 직접 지정 `{"1": 25, "5": 15}` |

매수를 안 주면 "초기 자금 최소 조합 + 거스름 여유"를 인원+1(은행)배 한다.

## track.cells — 칸

칸 수는 **4 + 4k** 여야 정사각 트랙이 된다(20 · 24 · **28** · 32 · 36). 첫 칸은 반드시
`start` 이고, 진행은 우하단에서 **반시계**다.

| kind | 필요한 키 | 하는 일 |
|---|---|---|
| `start` | | 지날 때 `salary`, 멈추면 `start_bonus` |
| `property` | `name` `group` `color` `price` `rents` `build_cost` | 사고 통행료 받는 땅 |
| `chance` | | 황금열쇠 카드 뽑기 |
| `tax` | `amount` | 그만큼 낸다 |
| `jail` | | 쉼터(3턴 쉬거나 더블로 탈출) |
| `go_jail` | | 쉼터로 보낸다 |
| `free` | | 아무 일도 없다 |

모든 칸에 `note`(칸에 찍히는 설명 한 줄)를 줄 수 있다.

### property 규칙

- `rents` 는 **오름차순**이어야 하고 최소 2단계다: `[빈 땅, 집 1채, 호텔]`
- 같은 `group` 을 전부 가지면 **빈 땅 통행료가 2배**가 된다(집이 있으면 적용 안 함)
- `build_cost` 가 0 이면 집을 지을 수 없다
- 한 그룹은 2~3칸이 좋다. 1칸이면 독점이 너무 쉽고, 4칸이면 거의 안 모인다

## cards.golden_key

```json
{"text": "심부름을 도왔어요. 20냥 받으세요", "effect": "gain", "value": 20}
```

**효과는 `text` 가 아니라 `effect` 가 정한다.** 문구만 고치면 인쇄물과 시뮬레이션이 갈린다.

| effect | value | 하는 일 |
|---|---|---|
| `gain` | 금액 | 받는다 |
| `pay` | 금액 | 낸다 |
| `move_to` | 칸 index | 그 칸으로(출발선을 넘으면 월급) |
| `move_rel` | ±칸 수 | 상대 이동 |
| `to_jail` | — | 쉼터로 |
| `jail_free` | — | 쉼터 탈출권(다음에 갇혔을 때 씀) |
| `nothing` | — | 아무 일도 없다 |

카드는 덱 순서대로 순환한다(섞기는 사람이 한다). 8~16장이 적당하다.

## 자주 만드는 오류

| 증상 | 원인 |
|---|---|
| `칸 수 29 로는 정사각 트랙을…` | 모서리를 4개 다 넣었다. 출발이 첫 모서리이므로 뒤에는 3개만 |
| `rents 가 오름차순이 아니다` | 집값이 빈 땅보다 싸다 |
| `권종으로 초기 자금을 정확히 만들 수 없다` | `denominations` 에 1 같은 작은 단위가 없다 |
| 게임이 안 끝난다(미종료율 > 0) | 임대료가 월급보다 훨씬 작다. 임대료를 올리거나 `start` 를 낮춘다 |
