# mmaa-welfare 사용 가이드

군인공제회 복지포털의 복지 상품·서비스 카탈로그와 공지사항을 수집해 표로 정리합니다.
**Claude에게 자연어로 부탁하면 됩니다** — "군인공제회 복지 상품 뭐 있어?", "공제회 공지 확인해줘"처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

API 키·로그인이 필요 없습니다. 공개 페이지만 수집합니다.

---

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 말하세요 |
|--------------|-----------------|
| 복지 상품 한눈에 | "군인공제회 복지 상품 전체 목록 보여줘" |
| 복지 키워드 검색 | "공제회 복지 중에 건강검진 관련 찾아줘" |
| 최근 공지 확인 | "군인공제회 공지사항 최근 10건 보여줘" |
| 공지 기간 조회 | "공제회 이번 달 공지 정리해줘" |
| 엑셀 저장 | "군인공제회 복지 목록 엑셀로 저장해줘" |

---

## 활용 시나리오

### 내가 쓸 수 있는 복지 찾기

```
군인공제회 복지 상품 중에 여행이나 리조트 관련 뭐 있는지 정리해줘
```

복지부조(축하금·위로금)부터 복지시설·제휴복지(건강검진·쇼핑·리조트)까지 전 항목이 `분류 | 그룹 | 항목 | 링크` 표로 나옵니다.

### 공지 정기 확인

```
군인공제회 공지사항 최근 10건 표로 보여줘
```

분양·금리 변경·서비스 중단 같은 공지가 날짜·조회수와 함께 나옵니다.

---

## 결과에 포함되는 정보

- **복지 카탈로그**: 분류 · 그룹 · 항목명 · 바로가기 링크
- **공지사항**: 날짜 · 제목 · 조회수 · 원문 링크

## 팁

- 복지 카탈로그는 페이지의 공식 메뉴 구조에서 추출하므로 항목·링크가 사이트와 정확히 일치합니다.
- 공지는 기본 최근 10건입니다. 더 필요하면 "3페이지까지"처럼 말하세요.
