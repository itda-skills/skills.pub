# fuel-price 사용 가이드

오피넷(한국석유공사) 주유소 **평균 유가**를 기준으로 **이달 출장 유류비 단가**를 계산하고, 직원에게 보낼 **공지문**까지 만들어 줍니다.
**Claude에게 자연어로 부탁하면 됩니다** — "이달 유류비 기준가 알려줘", "출장 유류비 공지문 만들어줘"처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

이런 분께 맞습니다: 직원들이 자기 차로 출장을 다녀오고, 매달(또는 매주) "이번 달 km당 유류비는 ○○원"을 정해 알려야 하는 총무·경영지원·행정 담당자.

---

## 사전 준비 — 없습니다

**회원가입·API 키 없이 바로 됩니다.** 오피넷이 누구에게나 공개하는 평균 판매가격 통계를 그대로 읽습니다.
현재 시세, 16개 시도별 가격, 지난 날짜·달 조회, 일간·주간·월간 시계열이 전부 키 없이 동작합니다.

한 가지만 준비해 두면 좋습니다 — **회사 규정의 연비·보정계수**. 예를 들어 "공인연비 12km/L, 실주행 보정 1.2" 같은 값이 있으면 km당 단가까지 한 번에 나옵니다. 값을 모르면 그냥 물어보세요 — 기준가만 알려주고 산식은 공지문에 적어 줍니다. 스킬이 값을 지어내지 않습니다.

> (선택) 오피넷 Open API 키가 있으면 일별 조회를 API 로도 할 수 있습니다. 대부분 필요 없습니다 — 아래 "선택: API 키" 참고.

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 요청하세요 |
|--------------|-----------------|
| 이달 기준가 확인 | `/fuel-price 이달 유류비 기준가 알려줘` |
| 직원 공지문 만들기 | `/fuel-price 출장 유류비 공지문 만들어줘. 연비 12, 보정 1.2` |
| 우리 지역 기준으로 | `/fuel-price 인천 기준 이달 휘발유 평균가` |
| 경유차 기준으로 | `/fuel-price 경유 기준으로 공지문 만들어줘. 연비 14` |
| 오늘 기름값 | `/fuel-price 오늘 기름값 얼마야` |
| 최근 추세 | `/fuel-price 최근 두 달 주간 휘발유 추세 표로 보여줘` |
| 지난 특정 달 | `/fuel-price 지난 7월 부산 휘발유 평균가 알려줘` |
| 특정 날짜 | `/fuel-price 8월 15일 경유 시세 알려줘` |
| 두 시점 비교 | `/fuel-price 6월 대비 8월 휘발유 얼마나 내렸어` |
| 표로 정리 | `/fuel-price 올해 월별 휘발유 평균가 표로` |
| JSON 으로 | `/fuel-price 이달 기준가 JSON 으로 줘` |

## 활용 시나리오

### 매월 초 — 출장 유류비 단가 갱신 공지

가장 흔한 쓰임입니다. 회사 규정(연비·보정계수)을 한 번 말해 두면 매달 같은 형식의 공지문이 나옵니다.

```
/fuel-price 이달 출장 유류비 기준가 공지문 만들어줘. 우리 회사 연비 기준 12km/L, 보정 1.2
```

```
[출장 유류비 기준가 안내 — 2026년08월 기준]

■ 기준 유가: 오피넷 2026년08월 전국 평균 보통휘발유 1,863.23원/L (전월 1,882.41원 대비 ▼19.18원)
■ 적용 단가: 186원/km  (기준가 ÷ 연비 12km/L × 보정계수 1.2)
■ 정산 산식: 자차 출장 이동거리(km) × 186원. 통행료·주차비는 실비 별도.
■ 적용 기간: 다음 월 기준가 공지 전까지

출처: 오피넷(한국석유공사) https://www.opinet.co.kr — 평균판매가격(부가세 포함, 원/리터)
```

이 문안을 그대로 카톡 단톡방·메일·그룹웨어 공지에 붙이면 됩니다. 문체를 바꿔 달라고 하면 숫자·기준일·출처는 그대로 두고 다듬어 줍니다.

### 사업장 소재 지역 기준으로

규정이 "사업장 소재 시도 평균"이면 지역을 말해 주세요. 16개 시도를 지원합니다.

```
/fuel-price 인천 기준 이달 휘발유 평균가로 공지문. 연비 12
```

지원 지역: 서울 · 부산 · 대구 · 인천 · 전남광주(광주·전남 통합) · 대전 · 울산 · 경기 · 강원 · 충북 · 충남 · 전북 · 경북 · 경남 · 제주 · 세종.
"경기도"·"인천광역시"처럼 정식 명칭으로 말해도 됩니다. 시·군·구 단위는 지원하지 않습니다.

### 경유차·고급휘발유 차량이 섞여 있을 때

제품별로 각각 요청하면 됩니다. 휘발유(기본)·경유·고급휘발유·등유 4종.

```
/fuel-price 경유 기준으로 이달 단가 계산해줘. 연비 14
/fuel-price 고급휘발유 기준 단가도 같이
```

### 유가 흐름 보기 — 단가를 바꿀 때인지 판단

기준가를 매달 바꾸는 게 번거롭다면 추세를 보고 결정하세요.

```
/fuel-price 최근 두 달 주간 휘발유 추세 표로 보여줘
```

```
| 기간 | 전국 보통휘발유 (원/L) | 증감 |
|---|---:|---:|
| 2026년07월4주 | 1,872.39 | — |
| 2026년07월5주 | 1,869.08 | ▼3.31원 |
| 2026년08월1주 | 1,866.16 | ▼2.92원 |
| ... | | |
```

### 지난 시점 조회 — 정산 소급·감사 대응

"7월 출장분을 7월 기준가로 정산해야 하는데 그때 값이 얼마였지?" 같은 상황입니다. 1997년부터 조회됩니다.

```
/fuel-price 지난 7월 부산 휘발유 평균가 알려줘
/fuel-price 2026년 8월 15일 경유 시세
```

### 오늘 시세

```
/fuel-price 오늘 기름값 얼마야
```

오피넷은 **전일자까지 확정 통계**를 매일 새벽에 냅니다. 그래서 "오늘" 이라고 물으면 가장 최근 확정일(보통 어제) 값이 나오고, 기준일이 함께 표시됩니다.

## 출력 형식 지정

| 원하는 형식 | 이렇게 요청하세요 |
|-------------|-----------------|
| 한 줄 요약(기본) | `/fuel-price 이달 기준가` |
| 기간별 표 | `/fuel-price 최근 6개월 월별 휘발유 표로` |
| 공지문 | `/fuel-price … 공지문으로 만들어줘` |
| JSON (다른 도구에 넘길 때) | `/fuel-price 이달 기준가 JSON 으로` |

결과에는 항상 **출처(오피넷·한국석유공사)와 통계 기준일**이 붙습니다. 오피넷 저작권 정책상 출처 표기는 지우지 마세요.

## 팁

- **규정값은 한 번만 말해 두세요**: "우리 회사 기준 연비 12, 보정 1.2" 라고 한 번 말하면 같은 대화에서는 다시 묻지 않습니다. 회사 규정 문서에 값이 있다면 그것을 그대로 쓰세요.
- **전국 vs 지역**: 관행은 **전국 월평균**입니다. 규정에 "사업장 소재지 기준"이 명시된 경우만 지역을 지정하세요. 둘 다 조회해 비교해 볼 수도 있습니다.
- **월간 vs 주간**: 정산 기준가는 월평균이 일반적이고, 유가 변동이 큰 시기에는 주간으로 좁게 볼 수 있습니다. "주간으로" 라고 말하면 됩니다.
- **비과세 한도는 별개**: 자가운전보조금은 월 20만 원까지 비과세(소득세법 시행령 §12)입니다. 이 스킬은 단가만 계산하니 정산 총액 한도는 경리 담당이 확인하세요.
- **정기 공지로 만들기**: Cowork 스케줄에 "매월 1일 유류비 공지문 만들어 카톡으로 보내줘"처럼 걸어 두면 원래 하던 일(매달 확인 → 공지)이 자동화됩니다. 이 스킬은 공지문 생성까지 맡고, 전송은 메신저·메일 스킬이 맡습니다.

## 안 될 때

| 증상 | 원인 / 해결 |
|------|-------------|
| "알 수 없는 지역" | 시·군·구나 "수도권" 같은 권역명. 위 16개 시도 중에서 골라 다시 요청 |
| "알 수 없는 제품" | LPG 등 4종(휘발유·고급휘발유·경유·등유) 밖. 오피넷 평균판매가격 통계에 없는 제품 |
| "… 까지만 있습니다" | 아직 통계가 안 나온 날짜·달(오피넷은 전일까지 확정). 날짜를 앞당기거나 "최신으로" |
| "기간 행이 없습니다" | 조회 기간에 통계 없음(너무 이른 과거 등). 기간을 조정 |
| "오피넷 화면 구조가 바뀐 것 같습니다" | 오피넷 사이트 개편. 스킬 업데이트가 필요하니 알려 주세요 — 임의로 다른 값을 쓰지 않습니다 |
| "오피넷 API 가 빈 결과" | (API 경로만) 키가 없거나 틀림. 오피넷은 에러 대신 빈 결과를 줍니다 — 키 확인 또는 기본 경로로 |
| "주간·월간 평균이 없습니다" | (API 경로만) API 는 최근 7일 일별만 제공. 기본 경로(키 불요)로 요청 |

## 선택: API 키 (`OPINET_API_KEY`)

기본 경로로 전부 되므로 **보통은 필요 없습니다.** 오피넷 Open API 로 최근 7일 일별 값을 받고 싶을 때만 발급합니다.

1. 오피넷 **유가정보 API 안내** 페이지를 엽니다 — https://www.opinet.co.kr/user/custapi/custApiInfo.do
2. 페이지 아래쪽 **「일반 API 이용 신청」** 을 누릅니다. 오피넷 회원이 아니면 회원가입(이름·휴대폰·이메일·아이디·비밀번호)이 먼저 뜹니다.
3. **자동 승인**되어 키가 즉시 발급됩니다(일반 API, 무료). 호출 제한은 페이지 안내 기준 하루 300회 — 이 스킬은 조회 1회에 1콜입니다.
4. 작업 폴더(Cowork 연결 폴더 / Claude Code 프로젝트 루트) 루트에 `.env` 파일을 만들고 한 줄을 넣습니다. 점(`.`)으로 시작하는 파일을 만들기 어렵다면 **`환경변수.txt`** 로 만들어도 똑같이 읽힙니다(메모장이 `.txt` 를 붙여 `.env.txt` 가 되어도 됩니다).

```dotenv
OPINET_API_KEY=발급받은_키
```

5. "API 로 최근 7일 일별 조회해줘" 라고 말하면 API 경로가 쓰입니다.

> 개발자라면 셸 환경변수나 `~/.claude/settings.json` 의 `env` 로 넣어도 됩니다.
> 프리미엄 API(전국 주유소 기본정보·판매가격 검색)는 공사와 제휴가 필요한 유료 서비스로, 이 스킬의 범위 밖입니다.

## 주의사항

- ⚠️ **평균가입니다.** 개별 주유소 가격·최저가 주유소 찾기는 하지 않습니다. 그건 오피넷 사이트·앱에서 직접 보세요.
- ⚠️ **시도 단위까지입니다.** 시·군·구 평균과 LPG(자동차용 부탄)는 지원하지 않습니다.
- ⚠️ **"오늘" 값은 전일 확정치입니다.** 오피넷이 매일 새벽 전일자 통계를 확정하는 구조라 당일 실시간가는 없습니다.
- ⚠️ **연비·보정계수는 회사가 정하는 값입니다.** 스킬은 기준가만 가져오고, 규정값을 대신 정해 주지 않습니다.
- ⚠️ **출처를 지우지 마세요.** 산출물의 "출처: 오피넷(한국석유공사)" 표기는 오피넷 저작권 정책상 필수입니다. 내부 공지 용도는 무방하지만 재배포·상업적 이용은 공사와 사전 협의가 필요합니다.
