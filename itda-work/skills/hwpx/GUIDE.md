한글 문서(.hwp/.hwpx)에 관한 세 가지 일을 하나의 스킬로 처리합니다 —
**읽기**(한글 → 마크다운·HTML), **양식 채우기**(내 양식의 빈칸만 값으로), **서식 생성**(내용 → 정부 서식 한글 문서).
**Claude에게 말로 부탁하면 됩니다.** 터미널을 직접 다룰 필요는 없습니다.

---

## 빠른 시작

```
이 HWP 파일 읽어줘
이 한글 양식 파일의 괄호 부분을 채워줘
이 내용으로 정부 한글 보고서 만들어줘
```

| 하고 싶은 일 | 이렇게 말하세요 |
|---|---|
| 한글 문서 내용 보기·요약·마크다운 변환 | "이 HWP 읽어줘", "마크다운으로 바꿔줘" |
| 우리 회사 양식에 값만 채우기 (서식 유지) | "이 양식 사본에 아래 값을 채워줘" |
| 내용으로 개조식 정부 서식 문서 만들기 | "정부 보고서 서식(.hwpx)으로 만들어줘" |

## 읽기 — 한글 → 마크다운·HTML

공공기관·기업의 HWP/HWPX 문서를 LLM이 이해하기 쉬운 마크다운으로, 또는 서식을 보존한 단일 HTML로 변환합니다.

```
이 보고서를 마크다운으로 변환해줘
HWP를 HTML로 변환해줘. 서식 그대로
```

- **표 평탄화**: 레이아웃 목적의 표는 자동으로 불릿·들여쓰기로 풀어 줍니다. 비교표처럼 행·열 교차가 핵심이면 "원본 그대로", "테이블 유지"라고 말하세요.
- **이미지**: 기본은 추출만 하고 설명(캡션)은 달지 않습니다 — "이미지 설명도 달아줘" / "본문만"으로 조절합니다.
- **HWP5(.hwp) 제약**: 제목 자동 감지·하이퍼링크 추출이 안 됩니다. 변환이 이상하면 "HTML로 우회해줘"라고 말하세요. 가능하면 .hwpx 를 쓰는 편이 안정적입니다.

## 양식 채우기 — 서식은 그대로, 값만

회사 양식(.hwpx)을 새로 그리는 게 아니라 **원본 사본의 글자만 바꿔치기**하므로, 표·번호·머리글·글꼴이 전부 그대로 유지됩니다. 양식에 `(부서명)`, `{{이름}}`, `《금액》` 같은 자리표시(placeholder)를 넣어 두는 방식과 궁합이 가장 좋습니다.

```
이 양식 파일에 채울 수 있는 자리를 먼저 보여줘
이 양식 사본에 채워줘 — 부서명은 내부감사팀, 담당자는 김서준
```

실제로 이렇게 진행됩니다 (실측 예시):

1. 자리 확인 — "채울 자리 보여줘" → `(부서명) ×1, (담당자) ×2` 처럼 양식 안의 후보를 알려줍니다.
2. 채우기 — 값을 말하면 사본을 만들어 치환하고, **자리마다 몇 번 채웠는지 보고**합니다.
3. 확인 — 결과 파일을 다시 읽기로 열어 값이 제대로 들어갔는지 교차 확인할 수 있습니다.

몇 가지 약속:

- **원본은 건드리지 않습니다** — 항상 사본으로 저장합니다.
- 못 찾은 자리는 조용히 넘어가지 않고 **반드시 알려줍니다** (표기가 다른 경우 1번으로 실제 표기를 확인).
- 같은 서식으로 이어진 글자가 내부적으로 쪼개져 있어도 자동으로 이어 붙여 찾아냅니다.
- **텍스트 치환 전용**입니다 — 표 행 추가·이미지 삽입·서식 변경은 이 경로에서 하지 않습니다.

## 서식 생성 — 내용 → 정부 서식 한글 문서

작성하려는 내용을 주면, 제목 박스·머리글(보고일·부서)·□/❍ 개조식 본문·표가 들어간 **대한민국 정부 범용 서식(.hwpx)** 문서를 만들어 줍니다.

```
이 내용으로 정부 한글 보고서 만들어줘. 보고일은 7월 28일, 부서는 기획조정실
민원 처리 통계를 표로 넣어서 한글 보고서로 만들어줘
```

생성 결과는 이런 모습입니다:

![회의결과 보고 — 생성된 한글 문서](/images/skill-guides/itda-work/hwpx-report/meeting-result.png)

- **표**: 헤더+데이터가 칸에 맞춰 들어가고, 칸별 정렬(왼쪽/오른쪽/가운데)·칸 안 굵게/기울임·내용 비례 칸 너비까지 지원합니다. 셀 병합은 아직 안 됩니다.
- **머리글**: 보고일·부서를 함께 말해 주는 것을 권장합니다(부서 생략 시 빈 자리표시가 남고, 안내해 드립니다).
- **팁**: 내용을 먼저 마크다운으로 정리·확정한 뒤 "이제 hwpx로 생성해줘"라고 하면 가장 깔끔합니다.

## 세 경로를 이으면 — 반복 서식의 자동화

세 작업이 한 스킬에 있어 이런 순환이 됩니다 (아래는 실제 검증한 흐름):

1. **생성**으로 우리 팀 주간보고 양식을 만들되, 바뀌는 자리는 `(부서명)`·`(담당자)`로 비워 둔다.
2. 매주 **채우기**로 그 양식 사본에 이번 주 값만 넣는다 — 서식은 매주 동일.
3. **읽기**로 결과를 열어 값이 맞는지 확인하거나, 지난 주 문서를 요약한다.

```
지난주 보고서 양식 사본에 이번 주 값 채워줘. 담당자는 김서준
```

## 제한사항

| 항목 | 내용 |
|---|---|
| 채우기·읽기 공통 | 암호 보호 파일은 처리할 수 없습니다. 먼저 암호를 해제하세요. |
| 채우기 | .hwpx 전용(구버전 .hwp 양식은 한글에서 .hwpx로 저장 후). 텍스트 치환만 — 표 행 추가·이미지·서식 변경은 비지원. |
| 읽기 | 수식·차트 등 OLE 객체는 추출되지 않습니다. HWP5는 제목 감지·하이퍼링크 미지원. |
| 생성 | 정부 범용 서식(gov-report)·보도자료 서식 기준 — 회사 고유 양식의 재현은 안 됩니다(그건 "양식 채우기"로). 셀 병합·원격 이미지 주소는 아직. |
| 기타 포맷 | PDF·DOCX 등은 다른 스킬(pdf, docx 등)을 사용하세요. |
| 외부 프로그램 | 필요 없습니다 — 스킬 단독(Python)으로 동작합니다. |
