# bai-notice 사용 가이드

감사원 통합공지를 수집해 표로 정리합니다.
**Claude에게 자연어로 부탁하면 됩니다** — "감사원 공지 확인해줘", "감사원 채용 공고 찾아줘"처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

API 키·로그인이 필요 없습니다. 감사원 화면이 실제로 쓰는 공개 JSON API 를 그대로 사용합니다.

---

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 말하세요 |
|--------------|-----------------|
| 최근 공지 확인 | "감사원 통합공지 최근 10건 보여줘" |
| 키워드 검색 | "감사원에서 채용 공고만 찾아줘" |
| 기간 조회 | "감사원 7월 공지 정리해줘" |
| 엑셀 저장 | "감사원 공지 최근 20건 엑셀로 저장해줘" |

---

## 활용 시나리오

### 공지 요약과 함께 훑어보기

```
감사원 통합공지 최근 10건 요약이랑 같이 표로 보여줘
```

다른 게시판과 달리 감사원은 게시물 요약문까지 제공해서 제목만으로 판단이 어려운 공고도 빠르게 걸러낼 수 있습니다.

### 채용·시험 공고 추적

```
감사원 채용 관련 공고 이번 달 것만 찾아줘
```

키워드 검색과 날짜 범위가 감사원 서버에서 직접 처리되어 전체 1,700여 건에서 정확하게 걸러집니다.

---

## 결과에 포함되는 정보

날짜 · 제목 · 담당 부서 · 요약 · 원문 링크

## 팁

- 키워드는 제목뿐 아니라 내용까지 검색됩니다 (서버측 검색).
- 감사원 사이트는 SPA 라 일반 웹 도구로는 빈 화면만 보입니다 — 이 스킬은 내부 JSON API 를 직접 호출해서 해결합니다.

## 안 될 때

- "API 스키마가 바뀌었을 수 있습니다" → 감사원 내부 API 가 변경된 것입니다. 스킬 업데이트가 필요합니다.
- 네트워크 오류 → 잠시 후 다시 시도해보세요 (자동으로 3회 재시도합니다).
