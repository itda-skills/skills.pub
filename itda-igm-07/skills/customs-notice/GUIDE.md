# customs-notice 사용 가이드

관세청 공지사항 게시판을 수집해 표로 정리합니다.
**Claude에게 자연어로 부탁하면 됩니다** — "관세청 공지 확인해줘", "관세청에서 원산지 관련 공지 찾아줘"처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

API 키·로그인이 필요 없습니다. 공개 게시판만 수집합니다.

---

## 자주 쓰는 요청

| 하고 싶은 것 | 이렇게 말하세요 |
|--------------|-----------------|
| 최근 공지 확인 | "관세청 공지사항 최근 10건 보여줘" |
| 키워드 검색 | "관세청 공지에서 원산지 관련된 것만 찾아줘" |
| 기간 조회 | "관세청 이번 달 공지 정리해줘" |
| 엑셀 저장 | "관세청 공지 최근 20건 엑셀로 저장해줘" |

---

## 활용 시나리오

### 매주 공지 훑어보기

```
관세청 공지사항 이번 주 것만 표로 정리해줘
```

날짜·제목·작성자와 원문 링크가 표로 나옵니다. 링크를 누르면 관세청 상세 페이지로 이동합니다.

### 업무 키워드 모니터링

```
관세청 공지에서 FTA나 원산지 관련 공지 있으면 알려줘
```

### 보고용 엑셀 만들기

```
관세청 공지 최근 30건을 엑셀 파일로 저장해줘
```

---

## 결과에 포함되는 정보

날짜 · 제목 · 작성자 · 조회수(엑셀) · 원문 링크

## 팁

- 기본은 최근 10건, 1페이지(10건)만 요청합니다. 더 필요하면 "3페이지까지 30건"처럼 말하세요.
- 관세청은 일반 웹 도구(WebFetch)로는 빈 페이지가 나옵니다 — 이 스킬이 브라우저 UA 로 요청하기 때문에 수집이 됩니다.

## 안 될 때

- "목록 테이블을 찾지 못했습니다" → 관세청 사이트가 개편됐을 수 있습니다. 스킬 업데이트가 필요합니다.
- 네트워크 오류 → 잠시 후 다시 시도해보세요 (자동으로 3회 재시도합니다).
