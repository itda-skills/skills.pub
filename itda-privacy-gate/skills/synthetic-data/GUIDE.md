# synthetic-data 활용 가이드

> 실제 환자·직원 데이터는 한 건도 필요 없습니다. **우리 문서의 칸 이름과 규칙**만 알려 주면 같은 구조의 가짜 데이터를 만들어 드립니다.

**아래 지침을 그대로 입력하면 됩니다** — `/synthetic-data 우리 입퇴원 대장 구조로 가상 데이터 50건 만들어줘`처럼요. 터미널 명령을 직접 입력할 필요는 없습니다.

## 시작하면 무엇을 묻나요

1. **"이 예시는 실제 환자·직원이 아닌 것을 확인합니다."** — 예시로 주시는 2~3건도 가짜여야 합니다. 실제 행을 주시면 진행하지 않습니다.
2. 어떤 문서인가요 — 프리셋(요양병원 4종 · 노인장기요양 4종)에서 가장 가까운 것을 고릅니다.
3. 프리셋 항목 표를 보고 **빼는 칸 / 더하는 칸 / 이름이 다른 칸**만 말씀해 주세요.
4. 항목 간 규칙(입원일 ≤ 퇴원일, 병실 → 병동 등)이 맞는지 확인합니다.
5. 몇 건 만들지, 채울 엑셀·한글 양식이 있는지 알려 주세요.

> ⚠️ 프리셋은 해당 업무의 문서 구조를 **예측해 만든 것일 뿐 정확하지 않습니다.** 고치지 않고 그대로 만들면 산출물에 "프리셋 그대로 생성 — 본인 서식과 다를 수 있음" 이 표시됩니다.

## 자주 쓰는 지시

| 하고 싶은 것 | 이렇게 말하세요 |
|---|---|
| 프리셋 그대로 빠르게 | `/synthetic-data 요양병원 입퇴원 대장 프리셋으로 30건만 만들어줘` |
| 우리 서식으로 | `/synthetic-data 우리 대장은 '연락처' 대신 '보호자 휴대폰'이고 '병동' 칸은 없어. 50건 만들어줘` |
| 엑셀 양식에 채우기 | `/synthetic-data 이 양식.xlsx 헤더 아래에 가상 데이터 100건 채워줘` |
| 한글 양식(1건 1장) | `/synthetic-data 상담기록지.hwpx 양식으로 가상 상담 기록 3장 만들어줘` |
| 실습용 판단 기준표 | `/synthetic-data 항목별 개인정보 등급 표도 같이 뽑아줘` |

## 무엇이 나오나요

- `data.csv` / `<문서>.xlsx` — 가상 데이터 (엑셀 첫 시트 「안내」 에 한계 고지)
- `report.md` — 규칙 위반 0 확인 + 한계 고지
- `field-definitions.md` — 항목별 개인정보 등급 표(1교시 판단 기준표)
- 한글 양식을 주셨다면 `<문서>-001.hwpx …`

## 꼭 알아 두세요

- 이름은 가짜이고 **동명이인이 일부러 섞여** 있습니다. 주민번호는 형식만 맞고 검증 자리가 틀려 실존 번호일 수 없습니다. 연락처는 `010-0000-…`, 주소는 `가상시 가상구 …` 입니다.
- 항목별 분포만 닮았고 항목끼리의 상관관계는 없습니다. 수식·스크립트·절차를 검증하는 용도이며 **경영 판단 수치로 쓰지 마세요.**
- 상담 내용 같은 자유 문장은 AI 가 가상으로 씁니다. 실제 상담 문장은 예시로도 주지 마세요. 실제 주민번호·휴대전화 형태가 섞이면 도구가 거부합니다.
- 원본 양식 파일은 절대 덮어쓰지 않습니다 — 산출은 새 폴더에 만들어집니다.
